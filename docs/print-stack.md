# 通用打印分层

“堆叠层”安排部件的上下关系，“打印层”是切片时的一次层高，两者在界面中分别命名。

## 操作

1. 在“工程 → 分层”设置工程的打印层高，启用分层。旧工程转换时明确确认：旧 Z 偏移和对象依附被分层替代，原厚度四舍五入为整数打印层（至少 1 层）。颜色、轮廓和修改器保持；转换可撤销。
2. 新增任意数量的堆叠层，双击名称重命名，用上下箭头调顺序。列表高层在上、底层在下；空层可删除。
3. 选中部件后，在“选区 → 叠放”中的“所属堆叠层”分配；多选部件可批量分配。层卡片只管理全局层结构，不把选择相关操作混入工程设置。
4. 区域厚度、部件统一厚度、拖动调高、键盘微调和底板厚度均使用整数打印层。界面另显示毫米换算。

没有按角色、颜色或名称识别的模板和快捷配置。

叠放位置是每个输出区域的作者态。部件页将其汇总为明确状态：全部区域在同一层时显示该层；区域间层不同、或层与独立放置混用时显示“叠放位置不同”；自由或依附放置但未归入打印层时显示“未分配堆叠层”；无法从当前求值确定时显示“无法确定堆叠层”。区域选区的叠放页只显示其实际层和起始高度。选择一个打印层仍是部件级操作，会把所选部件的默认设置和全部区域覆盖统一到该层。

同一部件跨层时，各层成员列表分别标记该部件的“部分区域”；这些层不能作为空层删除，仍可将整个部件统一移入其中一层。

## 计算规则

`source contour → surface modifiers → per-output appearance/thickness → print-stack placement → preview / compilation / STL / Blender`

打印层高 `h` 为工程参数，厚度记录的 `heightLayers` 是权威值。`heightMM = heightLayers × h` 是供几何引擎使用的派生值。更改 `h` 保留所有层数，统一更新物理尺寸。

设第 i 个堆叠层的打印厚度为 `T[i]`：

- `T[i] = max(该层所有参与成品的有效凸起区域的 heightLayers)`，无实体时为 0。
- `bottom[i] = sum(T[0..i-1])`，`top[i] = bottom[i] + T[i]`。
- 同层区域共用 `bottom[i] × h` 起始平面；各自的上表面由自己的厚度决定。
- 隐藏不影响打印高度；关闭「参与成品导出」会移除该部件对层高的贡献。
- 新底板通过已有的引用与外扩修改器生成，进入一个新的最底层，原有层统一抬升。
- 平面分色按层顺序与区域顶面排序；SVG 按堆叠层分组，保持相同覆盖顺序。
- 来源失败的层和更高层暂停定位，报告空的高度区间；低于故障的层仍有效。没有用旧高度快照代替失败的计算。

分层只消除不同堆叠层之间的竖直体积穿插，不自动修剪同层相交轮廓。同层面积关系仍由分区、布尔修改器控制。若下层表面高低不齐，上层统一放在最高点，局部可能悬空，需要实际实体检查；连续承托层宜统一厚度。旧式切削体块的深度也按打印层换算，从所在层的顶面向下切，贯穿切削保持原有语义。

## 模块与兼容

- `src/lib/print-stack.mjs`：参数、整数厚度、旧工程转换、通用层命令、最终定位。
- `creation-schema`：可选 `printStack` 与成员引用校验，新部件默认进入最高层。
- `creation-commands`：厚度与分层写入统一历史；局部厚度只写所选输出。
- `modifier-engine`：面运算结束后调用统一定位。旧工程未启用时继续使用旧对象依附。
- `creation-engine`：计算前物化毫米，编译时把最终 Z 与厚度写入实体；源面和修改器不会被打印分层拍平。
- `creation-number`、`creation-print-stack`、`properties/placement-properties`：共享数值编辑器、工程级层管理面板和选区叠放页；`printPlacement` 投影保留单层、混合、未分配和不可确定的区分，`printLayerId` 继续供兼容读取。
- 原构面体块编辑器在启用后也使用打印层数，避免从另一入口覆盖权威值。

工程 JSON 持久化层的稳定 ID、名称、顺序、部件成员与整数厚度，不存层高计算结果。API 的 `creation_inspect` 暴露 `creation.printStack`、`printLevels` 与每个面片的 `heightLayers / printLayerId`。命令参数见 `creation-api.ts`。

## 本轮验证清单

- 三层叠放：修改底层后，中层和顶层同步抬升；每层区域厚度独立。
- 层高换算、整数校验、JSON 重载、旧依附兼容。
- 层增删、重命名、排序、批量分配；删除非空层受限。
- 隐藏与参与打印的区别、空层、底板接入、故障向上暂停。
- 实体编译和 STL 体积与三段解析体积相符（允许 float32 顶点误差）。
- 最新 Sandrone 工程转换后保持 69 个面的几何和颜色；修改底层后，其他面的颜色、轮廓与局部厚度保持。
- 浏览器交互：转换确认取消与接受、建层、分配、整数厚度、层高切换、撤销、拖动调高；检查侧栏与三维画布布局。
