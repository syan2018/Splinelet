| 用户能力/控件 | 功能检查 | 视觉状态与证据 |
| --- | --- | --- |

| 菱形只挖金色嵌线 | 单面范围、关闭/恢复、删除/撤销；原曲线与模型不变 | 菱形露白、仍有浅凹侧壁；3D 近景 |

| 输出一致 | 实际工程 manifold；SVG/Blender 基于同一结果；不缓存几何 | 当前预览与几何报告 |

测试浏览器使用隔离上下文，不更改用户当前浏览器存储。

## 结果（2026-09-12）

- `test-modifiers.mjs`：10 组回归通过。覆盖局部差集、停用/删除/重载、顺序、分区左右身份、局部样式、合并结果换色/删色、对象嵌套实时引用、循环/缺失目标、动态底板及最终厚度叠放、真实头饰与实体。
- `test-modifiers-browser.cjs`：13 项正常 GUI 操作通过。覆盖单面/多面范围、聚焦 select 的 Ctrl+Z、启停、改名、相交切换、偏移添加、Esc 取消数值、拖动/菜单排序、删除、来源展开和自动保存重载。
- 探索检查：基础来源布尔步骤的开关可正确保存和恢复；失效范围在卡片显示具名错误，停用该步骤即可恢复有效输出。修改器错误入口定位修改器，不再误用旧分区诊断去停用无关样条。
- 另以简单矩形在 GUI 中用一条开放线分区，给单侧改金色/3mm，添加仅作用该侧的挖洞；另一侧保持奶油白/2mm。两侧面积分别 2400/3200mm²，三维结果与属性一致。
- 原有 `test-creation`、`test-region-isolation`、`test-live-surfaces`（21 项）、`test-crown-closures`（6 项）、`test-swatch-delete` 回归全部通过。
- TypeScript、生产构建、新模块定向 lint 通过。浏览器 pageerror 为 0。
- 实际工程：74 条路径、560 段曲线、原模型配方保持不变。菱形作用范围仅 `feature:body-band-64`；白底 3.15mm、金色顶面 3.48mm，形成 0.33mm 浅凹槽。
- 实体检查：19462 三角形、9733 顶点、1 个连通体、0 无效边、0 零面积三角形。体积 15641.308mm³。
- SVG 和 Blender 导出成功，Blender 附带的检查后实体报告一致，Python 语法解析通过。未启动 Blender，也未实物打印；导出的是最终实体和源贝塞尔，不是 Blender 原生修改器栈。
