# 修改器链与示例修复验收

日期：2026-09-26。本轮沿用原 Studio 界面，完成源编辑解耦、明确选择与修复、后段执行图、持久快照来源和示例重建。设计依据为[修改器链方案](../architecture/region-identity-redesign-2026-09-26.md)。以下数字是本机实测，不是通用性能或任意拓扑稳定性的承诺。

## 已实现

- pointer move 仅更新源曲线显示，不写撤销/作者预览，不请求区域；松手原子提交，交互队列只保留在途请求与最新待处理请求。
- 平面逐算子缓存及实际请求依赖闭包；外观、浮雕、放置、清理、实体从作者表先编译只读 DAG，再由统一后段执行器调度。执行图和展示依赖使用同一份节点定义。
- 当前端口结果与上次成功修订分开；预览/失败/旧响应不覆盖历史，partial 请求不误删快照。Typed mesh buffer 使用独立副本，参数卡片只读轻量状态。
- 输入重绑及兼容边界选择重选均有候选、预览、取消、确认、撤销及修订保护。区域已被另一选择占用时拒绝覆盖，不使用最近面猜测。
- 显式接边、锚点区域 Select、组内合并与跨组冲突检测。Select 和接边的复制、坐标重表达通过真实事务回归。
- 用户固化区域快照时创建断开的 Snapshot Source，随工程保存，可撤销；按历史世界变换重表达到当前 owner，不自动接替失败链。
- 独立 Part 实体失败保留其他分支的检查结果，但阻断聚合导出；保留原清理与 Manifold 简化语义。

## 原头发反例与示例

最终文件为 `public/sandrone-example.spl`，SHA-256：`29104444c49eae45a88b84a60cae73951986d6cfbcb5f8d83e382a355f1a766b`。

原失败顶点 `vertex:2933ceee9cbbad9896a2` 从 `[0.4444444444444482,13.888888888888888]` 移到 `[1.904298459042984,15.10543390105434]`；原始分区仍允许 12→11，具名选择及实体保持有效。浏览器回归实际拖动节点 20，使用原缩放比例和 `6px,-5px`，强断言实际模型坐标等于该反例；没有改成更小位移或另一个节点。随后测试控制柄、整线、撤销和保存重开。公开结果数从旧 73 调整为 68，是明确属性分组后的结果数，不是要求派生面数永远不变。

- 同组二维 union 对称差不超过 `1e-7 mm²`。
- 初始总体积 `16747.396746209 → 16747.396262765 mm³`，差 `-0.000483444 mm³`；容差 `0.167473967 mm³`。
- 头发颜色材料体积差 `+0.001761132 mm³`；容差 `0.020041655 mm³`。不能声称浮点体积逐位相等。
- 拆分 Cleanup 前后的实体及材料汇总严格相等。最终实体 24,068 三角形、1 连通体；有效 STL、通用和 Bambu 3MF 通过校验。
- 原失败移动后实体有效；一次源命令后一次撤销恢复文档、选择几何与实体/材料汇总。
