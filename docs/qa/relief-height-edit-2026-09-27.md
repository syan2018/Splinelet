# 浮雕高度编辑与内嵌示例复核

日期：2026-09-27。本轮针对修改高度仍触发长计算的问题；以下时间为本机单次实测，不是所有设备的性能承诺。

## 原因与修复

原属性命令对每个目标调用 `currentTarget → evaluateProgram → evaluatePlanar`，同步冷求值整个工程。部件批量编辑逐区重复这一过程。V5 的持久区域定义已经是作者目标，不需要在修改属性时重新证明几何存在。

修改后的属性命令校验完整持久引用、所属部件与锁定，再执行参数校验及事务；不读取几何源，不替换选择条件。断链后仍可更改已有定义的属性，制造求值继续报告原故障。临时面首次绑定与 V4 兼容路径保留真实求值。

平面缓存复用后段属性修改之前的完整只读结果；每次仍校验当前文档，自定义求值隔离。三维显示采用单位高度挤出，厚度和起始位置仅更新网格变换，轮廓坐标改变才重建；颜色和选中状态更新材质，删除、隐藏和卸载释放对应资源。没有修改制造实体或导出算法。

浏览器 CPU 记录进一步发现，Worker 接收端与修改器快照重复复制和深冻整份平面数据。原生 Worker 客户端现在接管已结构化克隆的消息，冻结一次后与会话、快照共享；自定义端点及可变网格缓冲仍保留隔离。旧响应、不同请求域和预览身份检查保持有效。

本示例的 `planar` 单字段 JSON 约 31 MB，属性更新继续传回相同几何仍有明显开销。因此浏览器私有通道加入经确认的平面快照复用：Worker 的确切缓存对象、epoch、请求域及不透明 token 全部匹配时省略三份平面字段，接收端用该请求持有的只读基准重组；否则传完整结果。当前颜色、厚度等后段结果仍更新，未改变公开求值 DTO。
