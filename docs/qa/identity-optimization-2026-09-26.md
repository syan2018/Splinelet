# 区域身份优化验收（2026-09-26）

本次已实现兼容 V4 文件的身份运行时优化。内置 Sandrone 的「求值＋创作视图投影」中位数从 **2358 ms 降至 589 ms（减少 75%）**；原样、颜色、厚度、pose 和源编辑五个场景的完整输出摘要均与原版相同。浏览器开发 fixture 中，颜色/厚度提交后的更新提示约持续 0.7–0.9 秒，但从提交事件到更新后两帧仍约 1.7 秒，不能把 Node 数字作为完整交互延迟。

这是 2026-09-26 的本机快照，不是跨设备性能承诺。优化前的 CPU 采样与来源编码评估保留在[原评估](evaluation-performance-2026-09-26.md)；此次使用独立的前后基线，不叠加原实验的收益。

## 浏览器交互

使用新的 browser/context、自动分配私有端口、真实 StudioApp 与 document Worker，未打开或修改用户正在使用的页面。通过颜色「应用」、厚度 Enter 和「撤销」按钮，各进行三轮。计时从实际捕获到提交事件开始，终点为更新提示消失后两个 requestAnimationFrame；这是绘制机会的近似值，未使用逐像素合成追踪。

| 操作     | 事件到更新后两帧 | 更新提示持续 | Worker 往返 |

| 颜色提交 |          1745 ms |       854 ms |      572 ms |
| 厚度提交 |          1663 ms |       730 ms |      482 ms |

每列均为三次中位数。没有测量同环境旧版浏览器基线，因此不声称浏览器端到端减少了 75%。提交事件到提示出现仍有约 0.9 秒差额，提示内还有调度、消息与界面投影开销；该计时只能定位阶段，尚未将提示前的耗时进一步归因到具体函数。

## 剩余空间

本次完成运行时身份匹配优化，但没有消除嵌套 JSON 来源 key 的存储膨胀，也没有收紧颜色/厚度修改的平面缓存失效范围。下一步应分别评估命令提交阶段的同步工作、按请求域裁剪、按依赖增量失效和 Worker 取消；当前曲面数较多时仍不能承诺即时更新。

来源 DAG/紧凑持久化标识需要单独的版本化迁移与复制重映射验证，不应通过截短 key、弱哈希、忽略 lineage 或静默重绑来换取速度。
