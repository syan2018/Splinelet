# 参考图叠放

顶栏“参考图”打开图层面板，“添加”支持同时选择多张 PNG、JPG 或 WebP；也可以直接把图片拖入已有工程。文件菜单“从图片新建”仍用于建立新的基准底图工程。

列表上方的图覆盖下方的图。选中图片后，用“上移／下移”调整顺序，“定位”把视野移到图片。附加图默认以保持宽高比的尺寸放在工程中央；所有图片在曲线与区域填色下面显示。“分色”隐藏图片，进入参考图调整时临时显示，完成后恢复原显示方式。

点击“调整”后，拖动图片边框内区域平移、四角等比缩放、外侧圆柄旋转；旋转时按 Shift 以 15° 对齐。面板可以输入中心毫米坐标、宽度和角度，或水平／垂直翻转。一次拖动记录一次撤销；拖动中 Esc、失焦或指针取消放弃本次移动。“完成”或选择绘图工具后恢复曲线编辑。锁定的参考图不可变换，但可调透明度、隐藏或明确删除。

参考图与作品对象相互独立：移动图片不移动曲线，隐藏或删除部件不改变参考图；图片不参与构面、布尔、浮雕或制造导出。复制图片共享资源，新增、修改和删除都支持撤销与重做。基准底图固定为坐标基准，只能改名、调透明度和隐藏；调整工程物理比例会同步缩放参考图与源几何。

自动描线、候选拐点和吸附仍只分析基准底图。沿附加图手动描线时，可用 Alt 直连落点，再调整贝塞尔控制柄；不要把附加图上看到的边缘当成自动识别来源。

参考图状态和图片字节一起保存到 `.spl`，浏览器草稿也可恢复。添加图不改变已有工程文件绑定。单张文件最大 30 MB，最长边超过 4096 像素时缩小；新增时限制总参考像素约 48 MP、当前图层最多 32 张、独立资源最多 13 个且共 48 MB。超限或批次中某张图片无效时，整批不提交。撤销所需的已删除图片在本次会话内保留；缓存达到 96 MB、约 96 MP 或 128 个资源时，会提示先保存并重新打开工程再添加。
