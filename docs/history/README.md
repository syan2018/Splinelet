# 历史记录

本目录保存当时的设计、实验、测试结果和证据，供问题追溯。记录中的“当前”“已完成”“待实现”均指记录发生时；当前产品行为请查阅[文档索引](../README.md)。

## 设计记录

- [编辑模型评审与重构](designs/editor-model-review-and-refactor.md)：旧模型评审、V4 提案与当时的实施计划。

## 验收与实验

[QA 快照目录](qa/) 保存按日期区分的运行记录，包括故障复现、尝试过的方案、性能数据和验收结果。文件名中的日期表示记录时间，不是产品版本；本地证据路径可能不随仓库提交。

## 记录边界

- 新的测试结果建立独立记录，写清输入、环境、命令、结果和未验证范围；不把旧结果更新成“最新通过”。
- 发现历史结论错误时，注明更正及其依据，保留原结论的上下文。
- 被取代的方案移入 `designs/`，注明历史性质并链接当前约定；仍适用的设计理由应整理到 `docs/architecture/`。
- 日志中产生的操作指南、API 契约和架构结论，需要单独更新对应的当前文档。任务状态留在 [tasks/](../../tasks/README.md)。
