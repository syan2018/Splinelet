# Splinelet 交互设计稿

版本：2026-09-19，评审稿。本文规定目标交互，并在末尾区分本次修正与待实现项；不是对所有现有界面的验收声明。

V4 的对象组织与渐进展开目标见[编辑模型重构方案](architecture/editor-model-review-and-refactor-2026-09-19.md)：默认围绕部件、线条、区域、颜色和厚度；复杂构造按任务展开，不默认显示内部数据域或四个技术目录。该方案的 U01–U06 为后续体验门槛，尚未实现；本文涉及整体移动源线、旧高级构造和路径移组的既有实现说明，随相应 V4 工作包切换，不据此维持第二套模型。

## 1. 核心决定

**V 只选择；A 修改轮廓；H 整体移动对象。** V 内点击、选区切换、拖过面或线条，都不能改变源线的位置或形状。多选也不赋予默认选择工具移动对象的能力。

这里的“修改轮廓”指编辑源样条的节点和控制柄；H 只整体平移部件全部来源，保持内部相对位置和形状。描线是明确的创建入口；颜色、厚度和构造参数仍由各自命名的工具或属性控件修改，不伪装成选择动作。

三个问题必须始终有可见答案：**我在哪个工具？我选中了什么？下一步会影响谁？**

- 工具决定动作：选择、节点、描线、上色、高低、移动对象。
- 选择层级决定范围：部件、区域、线条；进入节点工具后，再选择该线条内的节点。
- 显示方式只决定看见什么：底图、叠色、分色和三维预览，不决定修改范围。
- 一次明确编辑是一条撤销记录；选择、悬停、缩放、切换标签不进入工程撤销。
- 工程文件只在明确保存时写入；恢复草稿不等于已保存文件。

## 2. 工作区布局与反馈

保留单一创作工作区。属性导航使用竖排图标与文字，按“工具 / 工程 / 选区”分组；当前按钮向右与内容区连成一个面板。没有选择时整组“选区”隐藏；它不是随选择自动切换的第二套工作流。

| 位置         | 必须表达的信息                         | 示例                                            |
| ------------ | -------------------------------------- | ----------------------------------------------- |
| 顶栏         | 文件名、文件保存状态、保存与另存为     | `胸针.spl · 有修改未保存`                       |
| 顶栏“更多”   | 文件、帮助和 Agent API 的全局入口      | 不放源线、构面或浮雕工作台切换                  |
| 左侧工具栏   | 唯一激活工具和快捷键                   | `节点 A` 高亮                                   |
| 画布上沿     | 当前工具允许的操作                     | `选择 · 点选面或线 · 空白框选线条 · 不移动形状` |
| 画布选区提示 | 层级、数量、可执行下一步               | `线条：外轮廓 · 按 A 编辑节点`                  |
| 作品树       | 相同的语义选区、所属关系               | 选区定位到“右肩内”，不把父部件画成已选          |
| 属性栏顶部   | 修改影响范围，置于输入控件之前         | `仅此区域` / `整个部件，共 8 个区域`            |
| 属性导航     | 工具、工程、选区的稳定分类             | `工程 → 色卡` 不因点选区域跳走                  |
| 底栏         | 当前动作或失败原因，不冒充持久保存状态 | `已移动 3 个节点 · Ctrl+Z 撤销`                 |

高亮使用“当前选中”和“所属关系”两种不同强度：选中一个区域时可弱提示所属部件，但不能让用户误以为整个部件也被选中。隐藏的路径投影是内部数据，不应成为 Delete、拖动或 Ctrl+A 的隐式操作对象。

“工具”只显示随节点、描线、选择等工具变化的控制项；“工程”固定包含工程设置、项目色卡、打印方案和制作导出，工程高级构造位于工程设置；“选区”只在有选择时显示。线条只显示属性；只有单选一个部件或其区域时才显示构造修改器，多部件不显示单对象构造。工程分类不因选中区域、部件或线条而自动跳走。源线的节点与描线控制跟随工具显示，不能在选区属性内再嵌套“工程 / 描线 / 路径 / 节点”标签。

## 3. 工具与鼠标操作

| 工具       | 单击                                               | 按住拖动                   | 空白处                                     | 允许修改工程的入口                     |
| ---------- | -------------------------------------------------- | -------------------------- | ------------------------------------------ | -------------------------------------- |
| 选择 V     | 面→区域；线→线条                                   | 从面或线开始：不移动形状   | 单击清空；拖动框选线条                     | 无直接几何编辑；属性编辑须另有明确控件 |
| 节点 A     | 选择当前线条的节点或控制柄；点另一条线切换编辑线条 | 拖节点或控制柄修改形状     | 单击清空节点，保留编辑线条；拖动框选其节点 | 节点、控制柄、明确的节点操作           |
| 描线 P     | 落下锚点                                           | 移动预览，不拖旧对象       | 点击创建下一段                             | 新建、续画、闭合                       |
| 上色       | 给命中的区域上色                                   | 扫过多个区域，一笔一次撤销 | 不修改工程                                 | 命中区域的颜色／启用状态               |
| 高低       | 选择待调区域                                       | 只有明确的高度手柄改变厚度 | 不移动轮廓                                 | 厚度输入或高度手柄                     |
| 移动对象 H | 面或线→所属部件；修饰键增减部件                    | 整体移动选中部件的全部来源 | 保留选择，不移动对象                       | 明确的整体 XY 平移                     |

全工具通用：右键、空格拖动或中键拖动临时平移，松开后回到原工具；滚轮围绕指针缩放。临时平移不得清空节点选择，不得留下几何拖动状态。描线时右键短点结束当前线，超过 4 像素的右键拖动只平移视图。

三维预览只处理视角和区域选择：左键拖动旋转、右键拖动平移、中键或滚轮缩放。一次视角拖动结束后不再补发区域点击。进入节点或移动对象工具时回到平面视图。

## 4. 选择层级与多选

### 4.1 普通选择

| 动作                             | 结果                                         |
| -------------------------------- | -------------------------------------------- |
| 普通点击一个区域／线条／树中部件 | 只选该项，替换原选区                         |
| 画布 Shift / Ctrl / Cmd 点击     | 增减当前点击项；只有同层级才能累加           |
| 点击另一层级                     | 切换到该层级；不混合“部件 + 区域 + 线条”     |
| 树中 Shift 点击                  | 按当前可见列表连续选择同类条目               |
| 树中 Ctrl / Cmd 点击             | 增减同类条目                                 |
| 空白点击                         | 清空当前选择；不修改工程                     |
| `选择整个部件`                   | 显式把区域选区升级为所属部件，并更新范围提示 |
| `选择全部内部区域`               | 显式选中对应部件的区域，层级仍为区域         |

画布没有天然列表顺序，Shift 不得按内部 `scene.cells` 顺序选中看不见的中间项。

**V 框选固定为“框选线条”**：与矩形相交的可见源线入选，不选择区域，也不移动它们。追加框选只合并已有的线条选区；若之前选的是区域，不能顺带加入其所属部件的所有路径。界面必须明确标注“框选线条”，不使用模糊的“框选对象”。

**Ctrl+A 的目标规则**：在节点工具内全选当前线条节点；在普通选择中全选当前语义层级的可见条目；没有选区时默认全选可见线条。焦点在文本输入框内时只全选文本。当前实现仍有画布／侧栏差异，此项列为后续调整，不应通过隐藏的路径投影实现。

### 4.2 节点多选

首版范围：**同一条活动路径内多选节点，不跨路径选节点。**

- Shift / Ctrl / Cmd 点击节点：增减该节点。
- 空白框选：替换节点选区；按住 Shift / Ctrl / Cmd 框选：追加节点。
- Ctrl+A：选中当前路径全部节点。这样可在明确的节点层级整体移动这条路径。
- 拖动一个已选节点：一起移动所有已选节点及它们关联的控制柄，保持相对位置；不能在按下时先缩成单点。
- 多点选择后普通单击其中一点且未拖动：收为单点。
- 拖动未选节点：先选该点，再只拖该点。
- 单点显示其控制柄；多点不展示一堆可误触的控制柄。
- Shift 在拖动开始后限制水平或垂直位移；按下前的 Shift 用于增减选择。帮助需区分这两个时机。
- Delete 只删除已选节点；L 必须能确定单个曲线段，多点不允许猜测“最后一段”。

跨路径节点编辑若将来需要，另行设计显式进入方式、节点归属高亮和批量操作限制；本稿不把它混入普通对象多选。

## 5. 关键操作流程

### 查看一个区域，再改边界

1. V 点击区域：提示“仅此区域”；按住鼠标移动不会移动部件。
2. 点击“编辑线条”进入 A，并明确活动线条。
3. 如果区域由多条线构成，先显示其相关线条，要求用户点中实际要编辑的一条，不能偷偷选最后一条作为目标。
4. 选节点，拖动修改。关联区域重新计算，但选择一个面不等于移动其全部来源。
5. Esc 取消正在进行的拖动；正常松手后 Ctrl+Z 一次撤销。

### 移动一条路径

1. V 选择线条。
2. A 进入节点层级。
3. Ctrl+A 全选该路径节点，画布显示节点数量。
4. 拖任一已选节点；所有节点及控制柄平移，其他路径不动。

### 移动整个部件或多个编组

1. 按 H 或点击左侧“移动对象”，回到平面；当前区域或线条选择提升为所属部件。
2. 点击面或源线选择所属部件；Shift / Ctrl / Cmd 点击增减部件。
3. 拖动任一已选部件的面或源线，保留多选，整体移动所有选中部件的来源，包括同组隐藏源线；部件内部相对位置保持不变。
4. 从未选部件开始拖动时，只选中该部件，本次按下不移动；松手后再次按住已选部件才允许拖动。修饰键按下时的点击只增减选择；拖动开始后按 Shift 限制水平或垂直位移。
5. 小于 4 个屏幕像素不移动；Esc、失焦或捕获中断恢复起点；正常松手形成一次撤销。没有可移动源线的部件显示原因。
6. 整体平移期间只预览面、源线和派生曲线的位置，不逐次重建工程或求值构面；松手提交一次位移命令，再更新依赖几何。
7. 空白左键不移动对象；右键、空格或中键拖动只移动视图，保留选区。

### 修改多个区域颜色

1. V 选择区域，Shift/Ctrl 点击增减区域。
2. 属性栏写明“仅选中的 N 个区域”。
3. 通过命名控件应用颜色，形成一次撤销。
4. 不能把所属部件未选中的区域包含进来。“修改项目色”是另一项全局动作，必须单独命名。

### 保存并继续编辑

1. 修改后显示“有修改未保存”。
2. 草稿写入成功只表示可恢复，文件仍保持原内容。
3. 保存按钮或 Ctrl+S 才写当前工程文件；首次保存选择位置，另存为选择新文件。
4. 写入成功才显示“已保存”；失败保留未保存状态和可操作原因。
5. 保存期间出现新修改，已写入版本与当前版本必须分开判断，不能把新修改标记为已保存。

## 6. 作品树、属性与破坏性操作

- 名称单击只选中，箭头只展开，双击名称重命名。F 或定位按钮显式定位，不用重新选择来代替定位。
- 树中拖动负责排序或移组，反馈应显示“插入到某项之前／移入某部件”；不改变画布 XY 或物理高度。移组保持一次撤销。
- V 下 Delete / Backspace 不删除几何，提示“按 A 选择节点后删除”。不能把一个区域的删除意图翻译成删除整个父部件源线。
- 整条线或整个部件的删除使用明确命名的菜单／按钮。若会影响其他构造，先显示受影响项；常规无依赖操作可撤销，不要求每次弹窗。
- 属性输入必须绑定开始编辑时的实体。切换选择时未提交的输入不能写到新目标；Esc 恢复原值。
- 部件多选时，颜色、厚度和所属层等明确支持批量的操作必须说明范围；位置、依附和“参与成品导出”只在单选部件时显示，并提示先单选。
- 承托部件属于部件属性，不放在工程级的制作导出区。
- 两线围面、构面布尔、体块和零件属于高级构造。入口必须说明会打开高级构造编辑器，而不是伪装成普通区域属性。
- 看属性标签不切换工具。只有“编辑节点”“开始描线”等明确动作才进入编辑工具。
- 节点 A 无活动线条时提示“先选择一条线”；不能默认编辑隐藏的最后活动对象。
- 构造失败保留错误对象的身份与修复入口，不改选到另一个有效区域，不把旧预览当作可保存结果。

## 7. 手势、撤销与快捷键

节点与对象移动手势顺序：按下待定 → 移动达到 4 个屏幕像素 → 实时预览 → 松手提交。阈值与缩放无关。未达到阈值只有选择，不创建历史记录。

取消条件：Esc、窗口失焦、pointercancel、意外丢失捕获、检测到按键已释放而仍有旧手势。取消恢复手势开始前的几何，不创建撤销记录。正常松手释放捕获不会反过来取消已提交编辑。画布外松手也必须正确结束。

| 快捷键                  | 作用范围                                                           |
| ----------------------- | ------------------------------------------------------------------ |
| V / A / P / H           | 明确切换工具；文本输入时不拦截                                     |
| Shift / Ctrl / Cmd 点击 | 画布同类增减选；树中 Shift 连选                                    |
| Ctrl+A / Cmd+A          | 同当前层级全选；A 内仅当前路径节点；输入框内全选文本               |
| Delete / Backspace      | A 内删除已选节点；V 不修改几何                                     |
| L                       | A 内有明确单段目标时直连；P 内正在绘制时修正当前段；V 无作用       |
| E / M                   | A 内开放端点的续画／合并，必须有明确端点                           |
| Esc                     | 先取消手势或编辑草稿，再清节点选区，再退出当前选择；一次只处理一层 |
| Ctrl+Z / Ctrl+Shift+Z   | 工程撤销／重做；正在输入文本时服从文本编辑上下文                   |
| Ctrl+S / Ctrl+Shift+S   | 保存文件／另存为                                                   |
| F                       | 定位选区，不修改工程                                               |

### 仍需按此稿实现与验收

2. 画布固定显示工具说明与选区层级／数量；避免只靠短暂底栏提示解释范围。

## 9. 验收标准

| 场景                                 | 必须满足                                                   |
| ------------------------------------ | ---------------------------------------------------------- |
| V 点面、点线后拖动 100px             | 源线数据不变，未保存状态不因选择变化，不能产生几何撤销记录 |
| V 选区域按 L / Delete                | 工程不变，不删除父部件来源                                 |
| A 多选两个节点拖动                   | 只有这两个节点及关联控制柄按预期移动，其他节点不动         |
| A Ctrl+A 后拖动                      | 只有活动路径整体平移，其他路径不动；一步撤销完全恢复       |
| H 拖动多源部件或多个已选部件         | 全部来源等量平移，其他部件不变；一步撤销恢复               |
| 右键拖动面、线、节点或空白           | 只平移视图，工程和选区不变                                 |
| 节点或对象拖动后 Esc／失焦／捕获丢失 | 完全恢复起始几何，无新增撤销记录                           |
| 拖到画布外松手再悬停                 | 手势结束，不再改变几何                                     |
| Shift 点击不相邻的两个面             | 只选这两个面，不选内部列表顺序中的中间区域                 |
| 区域选择后追加框选线条               | 不夹带父部件其他源线                                       |
| 切换选区和属性标签                   | 工具与工程数据不被隐式改变                                 |
| 编辑、等待草稿、刷新                 | 草稿可恢复，工程文件在 Ctrl+S 前不变                       |

当前实现与操作说明见 [统一创作指南](creation-2026-09-19.md)、[源线编辑器](source-editor.md)。可复现测试入口见 [Scripts 目录](../scripts/README.md)。
