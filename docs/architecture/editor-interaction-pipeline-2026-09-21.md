# 编辑交互与求值管线

## 当前边界

对象变换分为显示手势和工程提交。`src/components/shared/transform-gizmo.tsx` 封装 Moveable 的移动、旋转与等比缩放控件，库负责命中、指针追踪与手柄计算；适配层将事件转换为文档像素空间的增量，并复用 `beginObjectGesture`。源路径与节点编辑继续使用 `useSourceDrag`。

G / R / S 切换变换模式，按下控件时只捕获身份、选框与基点，拖动以同一矩阵更新 SVG 源线、面、派生轮廓和控件代理；不打开模型 preview，不发布中间工程。松手通过 `object-transform` 命令提交一次，继续检查 revision、锁定和源身份。Esc、失焦、指针取消或丢失捕获同时复原代理与几何。节点编辑仍使用模型 preview，因为它需要实时改变曲线形状。

编辑会话的只读快照按状态缓存。历史保存深度冻结的文档，事务执行前仍建立独立草稿；读取当前状态不重复复制整个文档。旧快照不会随撤销、重做或后续编辑改变。

展示投影不得隐式运行几何求值。属性面板的修改器能力来自结构检查和已完成的求值结果；结果未就绪时不启用添加操作。真正执行修改器命令时仍重新验证，不能将界面能力当作授权或正确性依据。

普通查看和整体移动复用 Worker 已完成的曲线结果；节点与描线模式保留实时曲线求值。区域更新期间保留已有显示，选中对象的源线、构面及派生轮廓以同一变换预览，完成后撤去临时变换。

求值会话可复用内部拥有的、深度冻结的普通 DTO。TypedArray、ArrayBuffer 等无法通过冻结保护内容的数据仍在对外读取时复制。无订阅者时不为通知构造完整求值快照。epoch、revision、previewVersion 与过期结果检查继续生效。

## 完整轮廓的默认显示

“最终曲线”仍严格指显式发布的曲线输出。一个部件没有发布曲线、但直接发布 Fill 区域时，画布默认显示明确标记的“构面输入 · 完整轮廓”；使用该 Fill 的唯一输入及其坐标变换，不猜测最后一个成功的修改器阶段，也不修改工程的输出契约。显示不依赖部件是否选中。

## 后续优化的优先级

Worker 已增加单份局部平面结果复用：内置算子、无 datum／relation 的工程，以完整非 pose 文档、请求域及所有 world-result 引用双方的世界矩阵为失效依据。无关对象平移或旋转不重跑局部曲线／区域构造；源或接收方及其祖先改变世界矩阵时失效。每次仍验证文档；未知算子、自定义 resolver、datum／relation 使用完整求值。Worker 切换 epoch 清空缓存，只保留最近一份结果和键，不累计历史版本。

该路径仅跳过平面构造，仍重新计算浮雕、制造摆放、世界坐标导出视图及请求的实体；尚未实现任意编辑的逐算子增量更新，也未缩减 Worker 消息。

1. 将交互画布所需结果与完整求值／导出结果分开传输。画布需要可显示几何、身份、样式及诊断，不应每次搬运完整算子图和重复的作者态引用。
2. 建立按依赖失效的更新范围。先覆盖独立部件的刚体位移，再处理跨部件 world-result 引用、布尔依赖、承托与分层；不能只按选中 NodeID 跳过依赖。
3. 再评估跨 revision 的算子缓存。复用前必须计入输入坐标系、参数、几何设置和依赖身份，并与冷求值逐项对照。只加缓存而仍遍历和序列化完整输入，不保证性能收益。

除上述有限的局部平面复用外，这些仍是后续工作方向。本次实测和剩余瓶颈见 [真实工程验收](../qa/object-move-pipeline-2026-09-21.md)。

## 验证

`test-object-transform-frame.mjs` 检查嵌套旋转的选框、源线回退与固定缩放基点；`test-vector-transform.cjs` 通过真实鼠标操作验证三种控件的预览、取消、提交、缩放平移视图后的对齐与步进。`test-v4-transactions.mjs` 检查快照复用与不可变性；`test-v4-object-gesture.mjs` 检查显示手势不发布、一次提交及过期拒绝；`test-v4-worker-protocol.mjs` 检查普通 DTO 共享、可变缓冲隔离及过期结果拒绝。

`test-v4-planar-stage-cache.mjs` 对照完整冷求值，覆盖无关对象姿态复用、撤销、世界坐标引用双方、祖先移动、设置及请求域失效、无效 pose 拒绝和自定义 resolver 回退。

`test-object-move-pipeline.cjs` 默认从已提交的 Sandrone 示例通过公开 API 构造杯徽，再验证未选中时的完整轮廓、实际拖动、一次撤销及源定义不变。测试入口见 [Scripts](../../scripts/README.md)。
