# 构造链与失效处理

本文记录当前模块职责与构造失效协议。最初的检查日期为 2026-09-13；当前产品行为仍应以实现和回归测试为准。

这次修改确立的边界：几何由来源和运算动态产生；颜色、厚度归属于有稳定身份的输出；上游失效不产生可编辑或可导出的替代面。撤销保存的是工程指令，不把旧几何回灌进求值器。

## 类型明确的曲线阶段

`modifier-stages.mjs` 是求值器与 GUI 共用的阶段定义。新曲线部件和旧来源面使用同一条 `applyObjectModifiers` 程序；前者从精确贝塞尔开始，后者从来源适配层的面开始。每一步声明 curves/surfaces 输入与输出，不靠“有没有候选面”猜操作类型。曲线操作放到构面之后、面操作放到构面之前都暂停输出。

`curve-modifiers.mjs` 负责精确镜像、阵列和闭合检查。派生副本不写入 project.paths；只有 fill 采样成面。端点接合只影响派生数据，不给源线加段或补断口。闭合环按奇偶规则组成实面与内孔，中心缺口也保留。fill 输出使用 modifier ID 稳定定位并存入既有 modifier.styles；后续面修改器、颜色、高度、打印分层和实体导出继续共享原有求值结果，没有纹样专用网格旁路。

旧分区/来源 DAG 作为兼容输入层保留；本次不把旧数据强行改写成另一套操作历史。GUI 构造概览与 API `pipelines` 使用同一阶段表，列出来源、有序修改器、颜色厚度、分层实体输出。末两阶段仍由现有属性和打印设置驱动，并不是可以任意排序的三维网格修改器。

`creation_inspect` 等待根工程当前版本对应的已提交求值，而不是另算一份与编辑缓存脱节的结果；之后的 revision 命令使用同一快照。超时或求值失败明确报错。

`evaluateCurveProgram` 是构面引擎和交互预览共用的纯曲线求值器，只处理源线、镜像、阵列与构面输入。它保留每步精确控制点及端点诊断，填面失败不丢弃这些当前结果。画布拖动时同步执行这段轻量程序，完整曲面仍由 Worker 求值；派生线不写回工程、不进入拾取或实体导出。平面 SVG 与立体辅助线读取同一份曲线阶段数据。端点诊断与 fill 共用接合图，空间桶查找避免每次拖动扫描全部端点对。

`curve-transforms.mjs` 定义曲线修改器与节点吸附共用的模型空间仿射变换。`source-editor/endpoint-snap.mjs` 在拖动开始时建立只读目标快照：普通自由端点使用固定坐标，自身派生端点则求解 `p = T(p)` 得到精确接缝，避免吸附追逐随鼠标一起移动的副本。已有接缝上的单个端点沿该直线滑动，其他端点靠近时磁性吸附；已接合的目标不再用于连接，避免新增分叉。最终仍通过原节点移动操作平移锚点和相邻柄，沿用历史、取消与求值流程，不产生第二套修改器输出或持久约束。

## 一次兼容迁移的执行

旧文件没有区域身份，只有旧面积和样式。`creation-styles.mjs` 只负责此类导入：按来源 / 全局一一对应尝试绑定；有歧义则阻断，不生成条纹区域。成功后 `surfaceGraph` 接管，旧 paints 被清空。之后移动源线不运行面积匹配。旧独立来源 recipe 保留为 DAG，不再由“画分区 / 挖洞”按钮隐式转换成填色快照；`continue_partition` 已退出日常流程。

新分区的子轮廓继承父面样式，然后各自可编辑。若既有分区关系被破坏，默认停止整个受影响的对象输出链；其他无依赖的对象继续求值。这里采用保守的对象级暂停，尚不是 Blender 式每个输出插槽各自显示最后一次成功几何。没有保存旧网格来冒充当前结果。

## 修复协议

1. 移动 / 修复来源，使旧输出关系再次成立：自动恢复，样式不变。
2. 旧分区网络确实需要改变：查看重建影响，确认重建输出。相同来源的输出和样式保留；失效输出解除；新输出使用部件默认设置。引用旧输出的修改器继续暂停，不能被悄悄重定向。
3. 修改器不再需要：删除单步，或确认“移除此步及下游”。源路径保留；被删除步骤的输出样式随其解除；可撤销。

## 检查范围与证据

构造链测试检查一次绑定、对象移动、单面改色 / 改高、未编辑记录保持、保存重开、分区失效、依赖等待、修复恢复、确认重建、解除与导出阻断；另保留最小化的 non-noded 回归 fixture。旧的 `test-creation.mjs` 兼容别名已删除，当前入口为 `test-construction-pipeline.mjs`，不再要求旧的条纹合并和快照重写行为。

另运行现有修改器回归，覆盖布尔作用范围、嵌套对象、修改器排序、厚度与底板依附、来源失效和头饰实体导出。浏览器只核对局部颜色 / 厚度 / 撤销，以及失败提示与解除链路确认；没有重复整轮描线或全面 UI 遍历。

基础来源 DAG 和对象修改器栈仍是两个有明确输入输出的层级，不宣称已变成通用节点编辑器。今后新增运算应进入来源算子或修改器栈，声明输入引用、输出身份及失效条件；GUI 只发工程命令，禁止在交互按钮里改写求值结果或重新猜样式。
