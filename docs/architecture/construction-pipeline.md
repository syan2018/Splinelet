# 构造链与失效处理

本文记录当前模块职责与构造失效协议。最初的检查日期为 2026-09-13；当前产品行为仍应以实现和回归测试为准。

这次修改确立的边界：几何由来源和运算动态产生；颜色、厚度归属于有稳定身份的输出；上游失效不产生可编辑或可导出的替代面。撤销保存的是工程指令，不把旧几何回灌进求值器。

## 模块职责

| 环节 | 实现和数据 | 失效处理 / 本次处理 |
| --- | --- | --- |
| 描线、节点、手柄、平移 | `public/selection.mjs`、节点编辑模块修改路径；不修改面 | 构造随路径版本重算。旧 paints / seed 的平移仅为未迁移工程兼容；已绑定工程不读取它们 |
| 基础轮廓、描边宽度、两线围面、封口 | `region-engine.mjs` 的来源 DAG；引用源路径 / 父区域 | 保留原始 recipe。旧 split 由空间 seed 一次绑定到有向边界标识，后续不再靠 seed 选面 |
| 旧工程分区网络 | `partition-engine.mjs` | 从 `creation-engine` 拆出为来源阶段。保留已有连接分组，输出有向来源边的轮廓签名；失去既有输出即暂停 |
| 新分区 | `modifier-engine.mjs` 的 split | “分区”用途快捷操作生成同一修改器栈中的步骤，绕过旧网络，避免重复执行；不能贯穿时停止，不再返回完整父面冒充输出 |
| 布尔、挖洞、偏移 | 同一修改器栈 / 来源子栈 | 已删除独立 `creation-holes.mjs` 和二次挖洞链。混合几何只保留有面积的部分；每步验证输出约束；后续步骤显示等待 |
| 输出身份 | `surface-lineage.mjs` | 由源边及其方向、边界循环次序、孔边界组成，不使用面积排序；重复身份或失去引用均停止。输出记录不保存多边形 |
| 颜色、厚度 | `surfaceGraph.outputs[].style`、`modifier.styles`、旧 feature 属性 | 局部命令只改所选输出记录；不求交、不刷新兄弟区域。色卡删除也遍历这些引用 |
| 拉伸 / 叠放 | 面片结果 → 厚度 → 最终依附高度 | 在修改器结果产生后计算叠放，使用最终厚度；依附来源失败、缺失或成环阻断后续结果 |
| 集合 / 路径整理 | `creation-path-transfer.mjs` | 区分草稿线与构造输入；迁移整体构造时一并维护输出引用和样式，禁止丢掉仍被引用的来源 |
| 保存、撤销、异步结果 | 工程 JSON + `bindSurfaceGraphs` | 成功导入后一次保存引用绑定，无新历史动作；陈旧 worker 结果不能覆盖新工程；暂停也可保存 / 撤销，失效约束保留到下次打开 |
| 预览、SVG、Blender、STL | `evaluateCreation` / `compileCreation` / `buildSolid` | 预览和导出消费同一条已验证链。暂停对象没有可拾取的伪造面；相关导出拒绝继续 |
| GUI / API | 修改器页的构造链、步骤错误、等待提示 | 定位源线修复会自动恢复；重建输出、移除此步及下游都明确提示影响且可撤销 |

## 一次兼容迁移，与日常求值分离

旧文件没有区域身份，只有旧面积和样式。`creation-styles.mjs` 只负责此类导入：按来源 / 全局一一对应尝试绑定；有歧义则阻断，不生成条纹区域。成功后 `surfaceGraph` 接管，旧 paints 被清空。之后移动源线不运行面积匹配。旧独立来源 recipe 保留为 DAG，不再由“画分区 / 挖洞”按钮隐式转换成填色快照；`continue_partition` 已退出日常流程。

新分区的子轮廓继承父面样式，然后各自可编辑。若既有分区关系被破坏，默认停止整个受影响的对象输出链；其他无依赖的对象继续求值。这里采用保守的对象级暂停，尚不是 Blender 式每个输出插槽各自显示最后一次成功几何。没有保存旧网格来冒充当前结果。

## 修复协议

1. 移动 / 修复来源，使旧输出关系再次成立：自动恢复，样式不变。
2. 旧分区网络确实需要改变：查看重建影响，确认重建输出。相同来源的输出和样式保留；失效输出解除；新输出使用部件默认设置。引用旧输出的修改器继续暂停，不能被悄悄重定向。
3. 修改器不再需要：删除单步，或确认“移除此步及下游”。源路径保留；被删除步骤的输出样式随其解除；可撤销。

## 检查范围与证据

构造链测试检查一次绑定、对象移动、单面改色 / 改高、未编辑记录保持、保存重开、分区失效、依赖等待、修复恢复、确认重建、解除与导出阻断；另保留最小化的 non-noded 回归 fixture。旧的 `test-creation.mjs` 兼容别名已删除，当前入口为 `test-construction-pipeline.mjs`，不再要求旧的条纹合并和快照重写行为。

另运行现有修改器回归，覆盖布尔作用范围、嵌套对象、修改器排序、厚度与底板依附、来源失效和头饰实体导出。浏览器只核对局部颜色 / 厚度 / 撤销，以及失败提示与解除链路确认；没有重复整轮描线或全面 UI 遍历。

基础来源 DAG 和对象修改器栈仍是两个有明确输入输出的层级，不宣称已变成通用节点编辑器。今后新增运算应进入来源算子或修改器栈，声明输入引用、输出身份及失效条件；GUI 只发工程命令，禁止在交互按钮里改写求值结果或重新猜样式。
