# 选区属性贡献架构（2026-09-26）

右侧属性栏把工程级页面与选区页面分开。工程页面仍由导航宿主固定提供；选区页面由静态 registry 根据当前选择的语义目标筛选。该机制组织现有界面模块，不是动态插件加载机制。

## 目标与选择

`selectionPropertyTarget` 将当前选择和场景树投影为 `none`、`path`、`region`、`shape`、`group` 或 `mixed`，并携带选中数量、所属 Shape 数量和组数量。它只读取选择和树，不修改文档、选择或求值结果。

`PropertyNavigation` 接收已解析的贡献项并渲染“选区”分组。调用者保存请求的页面 ID；`resolvePropertyPage` 仅在该页面不再支持新的语义目标时回退到第一个可用贡献项或工具页。因此同一页在连续的兼容选区之间保留，导航本身不产生撤销记录。

## Registry 与贡献项

`src/components/creation/properties/property-registry.ts` 是组合根。每个 `PropertyContribution` 声明稳定 `id`、显示元数据、排序值、`supports(target)` 和 `Panel`。`resolvePropertyContributions` 检查重复 ID、按顺序筛选，并且不重排 registry 本身。

当前语义范围如下：

| 选择                            | 可用贡献页             |
| ------------------------------- | ---------------------- |
| Shape 或区域                    | 形状、颜色、浮雕、叠放 |
| 单一所属 Shape 的部件或区域选区 | 构造                   |
| 单一 Shape                      | 输出                   |
| Shape                           | 承托                   |
| 源线                            | 源线                   |
| 场景组或混合组选择              | 层级                   |

叠放页对区域只显示实际制造层与起始高度。对 Shape 或多 Shape 选择，它使用 `printPlacement` 读取单层、混合、未分配或不可确定状态；选择一个层调用既有部件级命令，因此会统一所选部件的全部区域。该页不把区域查看扩展为按区域赋层命令。

## Panel 与上下文

宿主在每次渲染中构造一个 `PropertyContext`，其中包含只读文档/场景投影、选择范围、禁用状态和既有行为回调。Panel 通过这个上下文调用颜色、厚度、叠放、构造、承托、输出、源线或层级的已有命令；它不接收可写 Project，也不拼装第二套状态。

命令继续进入既有 canonical command、修订保护、历史和持久化路径。贡献页的拆分不能改变选择语义、写入范围或一次操作对应一次撤销的边界。

## 派生曲线预览

`curve-preview-selection.mjs` 将完整预览与当前选中部件的阶段选择分开。未选择部件时保留每个对象的最终或默认完整结果；选中一个部件或仅属于它的源线、区域时仅替换该部件的预览阶段，并保留其他对象的完整结果。预览选择是显示状态，不写入工程，也不影响撤销或导出。

## 扩展方式

新增页面时，在 registry 注册一个带唯一 ID 的贡献项，并把它的可用条件放在 `supports` 中。Panel 应复用 `PropertyContext` 已提供的 canonical 回调；若需要新写入，应先在命令层定义并验证其选择范围、版本检查和撤销语义，再把回调加入上下文。不要让导航项、Panel 或预览状态直接变更规范文档。
