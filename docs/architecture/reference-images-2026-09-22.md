# 多参考图的领域边界

Reference 是世界毫米空间中的视觉辅助，不是 Shape 或 Group，不占用作品树，也不自动成为某个对象的子项。当前版本不引入图片随对象移动的隐式关系。将来如增加关联，应设计明确的“绑定／解除绑定”，定义世界与局部坐标换算、复制、删除和父组变化语义，不能通过名称或当前选择猜测归属。

`Document.assets` 保存不可变资源描述，字节由持久化会话持有；`Document.references` 保存资源引用、名称、像素尺寸、`pixelToWorld`、透明度、显示、锁定，以及可选 `role` 与 `order`。基准图保持校准矩阵，附加图可独立仿射变换。显示矩阵为 `worldToPixel × pixelToWorld`，参考图不会反向影响 `sourceFrame`。

参考图命令统一经过编辑事务与历史。导入解码期间捕获 epoch/revision，提交前拒绝陈旧结果；批次先完成解码和容量检查，再注册资源并原子添加图层。失败撤回新增 URL 与字节。图层复制共享资产，删除最后引用时从当前 Document 移除资产描述；会话资源池保留撤销／重做所需内容，关闭或成功切换工程后释放 Blob URL。持久化快照只选择当前 Document 声明的资源。

Studio presentation 继续提供基准图兼容 `reference`，同时提供有序 `references` 和由宿主管理的资源 URL。主画布和构面视图使用相同的参考图绘制组件。画布调整使用局部草稿，释放指针后一次提交；取消不进入文档。普通编辑时图片不接收指针命中，调整状态阻止曲线操作。

几何求值按去掉 `references` / `assets` 后的文档内容缓存，保留 epoch 和求值域区分。图片编辑仍产生新的编辑 revision，求值请求继续验证完整 revision/preview 身份；只复用无图片依赖的求值结果，不放宽陈旧命令或结果校验。自动描线 Worker 仍使用基准图，不合成多图输入。
