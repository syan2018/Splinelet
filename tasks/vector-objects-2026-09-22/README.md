# SVG 笔迹与对象变换

产品说明以 [源编辑器指南](../../docs/source-editor.md) 为准。本任务保留共享 Studio、V4 规范文档及现有布局，不引入第二套可写模型。

## 工作包

- [x] 大纲重命名：进入编辑时全选一次；连续输入、移动光标、Enter 提交和 Esc 取消；独立修复提交。
- [x] 对象变换：H 工具移动／旋转／等比缩放；数值输入与显示预览；组后代和共同中心；锁定／跨选区引用保护；一次撤销。
- [x] SVG 导入：精确路径、填充孔洞、描边构面、尺寸与贴附、独立场景组、整批校验与撤销。
- [x] 签名实例：手写 Sandrone SVG、可复现生成脚本、保留输入工程的新 `.spl`、实际 3D 预览。
- [x] 回归：独立单测、原 Studio 隔离浏览器交互，以及类型、lint、单测、Web／桌面构建和 Rust 检查。

具体输入、生成参数和验证边界见 [2026-09-22 验收](../../docs/qa/vector-objects-2026-09-22.md)。
