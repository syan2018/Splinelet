# 选区属性贡献与曲线预览（2026-09-26）

本任务处理选区属性的领域边界、派生曲线预览的选择作用域，以及堆叠层混合值的显示。当前架构约定见[属性贡献架构](../../docs/architecture/property-contributions-2026-09-26.md)。

## 工作包

- [x] 预览：未选择时显示完整结果；仅显式选区可改变所属部件的阶段或临时隐藏辅助曲线；取消选择恢复完整结果。
- [x] 属性：将形状、颜色、浮雕、叠放、构造、承托、输出、源线和层级拆成独立贡献页，统一解析可用页面与回退。
- [x] 状态：复用现有选择、命令、修订与撤销管线；切换选区清除未提交的属性输入。
- [x] 分层：区分单层、区域/部件混合、未分配和无法确定；层列表保留部分区域成员与删除保护。
- [x] 文档与验收：同步当前指南；验证结果和限制保存在[本次 QA](../../docs/qa/property-contributions-2026-09-26.md)，旧浏览器用例失败不记为通过。
