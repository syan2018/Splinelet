- 旧 Region 被多个 Feature 复用时显式实例化输出；保留独立厚度、样式与动态附着，不能靠去重或冻结几何消除冲突。
- 迁移报告进入 Studio 会话与可见提示；不能只验证文档结构便把无法求值的工程报告为成功。
- 原工作区消费明确的只读 V4 显示投影；旧 Project 仅用于旧格式适配。
- 内置示例由用户指定工程的副本更新，保持 `/sandrone-example.spl`；原文件不修改。
- 旧 Sandrone 移入独立兼容性 fixture，当前示例与历史迁移各自有可重复验证。
