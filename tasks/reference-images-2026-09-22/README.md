# 多参考图交付

范围：在原 Studio 与 V4 Document 上实现独立参考图层，保留基准图和原有曲线交互。设计以[参考图架构](../../docs/architecture/reference-images-2026-09-22.md)为准，操作说明见[参考图指南](../../docs/reference-images-2026-09-22.md)。

工作包按模块分工，主代理负责会话、持久化与画布接线；命令、面板和浏览器回归由各自独立工作包实现。

- [x] 模型与命令：role/order、基准保护、排序、变换、复制、删除、原子验证与撤销单测。
- [x] 资源会话：批量导入、资源共享、URL 生命周期、文件绑定保持、保存重开和恢复单测。
- [x] 界面：原画布多图显示、独立面板、变换手柄与取消、构面视图共享渲染。
- [x] 验证：全库检查、Web/桌面构建、隔离浏览器交互验收已执行，结果及 Windows 换行检查限制见[验收快照](../../docs/qa/reference-images-2026-09-22.md)。

本任务不包括附加图自动拟合、对象绑定、裁剪或透视编辑。任务状态不替代产品文档；验证完成后补充实际结果。
