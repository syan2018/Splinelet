# 工作包 1：基线与反例

范围：验证脚本、最小 fixture、隔离浏览器、带日期的 QA；不修改来源工程。主代理判断几何和身份结论，不能仅按状态或数量验收。

- [x] 记录用户文件与基线 SHA-256；审计输入不变。
- [x] 区分当前契约阻断与去契约实验；后者仅用于诊断，不作为修复。
- [x] 建立直线分割正方形的拆分/合并、柄变化、反转审计。
- [ ] 将期望不变量转为修复后的常规回归；已知缺陷不能写成“断言失败行为正确”的绿色验收。
- [ ] 增加闭合轮廓删点/拆点、循环起点变化、重复交点、镜像/阵列实例、对称区域、微小间隙、真实分裂/合并的最小数据。
- [ ] 每个区域按作者 ID 检查其几何、颜色、厚度、放置；同时比较源形状、孔洞和实体，不能只比区域集合或总面积。
- [ ] 保存重开、撤销重做、复制与冷求值重复上述检查。
- [ ] 浏览器测源输入到源线绘制、提交到区域完成、长任务、clone、Worker 往返；固定样例、构建与机器，预热后至少 30 次，给 p50/p95/max。

验收：反例可独立运行且能在修复前揭示问题；修复后的检查对所有正确不变量通过。静态示例校验继续保留，但明确不代替编辑验收。
