# 区域身份与源线编辑链收敛

日期：2026-09-26。当前交付为故障审计、可执行反例、底层来源传递探针与已收敛的设计决策，产品重构未完成。此任务承接用户反馈的删点后头发构面阻断和源线编辑卡顿；不以更新示例替代算法修复。

语义依据：[架构决策](../../docs/architecture/region-identity-redesign-2026-09-26.md)：声明式区域定义、带来源平面构造、单向纯求值。撤回初稿的持久 identityPending 和 Worker 自动接受映射；所有作者数据仅由同步命令改变。事实依据：[复审记录](../../docs/qa/spline-edit-failure-2026-09-26.md)与[设计核查](../../docs/qa/region-design-2026-09-26.md)。当前产品语义仍见[构造链](../../docs/architecture/construction-pipeline.md)。

## 顺序与边界

1. [基线与反例](01-evidence.md)：固化几何、身份、赋值和编辑延迟的验收标准；先做来源图和选择器表达能力原型。
2. [源线交互与调度](02-interaction.md)：先建立独立于派生区域的编辑反馈；可以在现有文件协议上实施。
3. [区域定义与迁移](03-identity.md)：证明逻辑基准、选择器表达能力、纯求值与命令原子性，再切换协议及全部消费者。
4. [增量求值与收尾](04-evaluation.md)：依赖缓存、显示 patch、故障局部化与旧逻辑退出。

第 2 包完成不能宣称身份已修复；第 3 包完成不能宣称编辑已流畅。示例最终验收必须等待全部工作包通过，保留原艺术源数据；每包只改变一个行为边界，不重写工作区布局。
