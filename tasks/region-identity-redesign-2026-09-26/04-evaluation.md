# 工作包 4：增量求值与收尾

范围：ChangeSet、依赖 DAG、算子缓存、Worker DTO、显示诊断及旧身份运行逻辑退出。保留几何内核、唯一作者态和严格导出完整性检查。

- [ ] source/pose/appearance/relief/placement/presentation 变化分域失效。
- [ ] 依赖包含跨 Shape、关系、世界坐标和实例；逐项与无缓存冷求值比较。
- [ ] 仅返回受影响显示 patch；完整 snapshot 用于显式检查/导出，来源 DAG 按 ID 共享。
- [ ] 请求和响应的 clone 所有权清楚，实测次数与耗时；不能仅删除 clone 破坏只读边界。
- [ ] 来源图留在求值侧，UI 按需拿显示数据；不将每个上游图复制进每个持久引用。
- [ ] 导出/检查的显式修订捕获与 latest-only 预览分类；预览不能吞掉已捕获请求。
- [ ] 几何、身份、赋值、制造状态分开；根因能追到源路径/算子，未知绑定只影响其依赖范围。
- [ ] 从正常运行路径删除嵌套身份字符串解析与隐式兼容重绑；旧解析器仅供导入。
- [ ] 真实示例进行删点、拆点、反转、柄/点拖动、连续编辑、撤销、重开与分色导出，全部保存为测试副本。
- [ ] 执行类型、lint、Node、格式、Web/Desktop 前端及 Rust 门禁；隔离浏览器覆盖两端，记录仍有的基线问题。

验收：不相关算子执行计数为 0；增量和冷求值在每个相关输出上一致；错误状态不会伪造已完成成品。性能报告同时列源线响应、区域完成、对象规模与真实 clone/Worker 成本。只有全部包通过后才能重新给示例作“可持续编辑”的结论。
