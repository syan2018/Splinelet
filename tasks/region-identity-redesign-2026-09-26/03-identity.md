# 工作包 3：声明式区域定义与迁移

范围：区域定义 schema/codec、逻辑曲线基准、选择器解释、全部赋值消费者、复制和旧格式导入。跨模块语义由主代理统一决策；求值没有写 Document 的权限。

- [ ] 先用正方形反例和局部源编辑证明持久区域定义、用途/实例及选择器的独立冷求值；runtime cell handle 不能作为持久 ID。
- [ ] 反转和循环换起点只是表示变更时，命令显式改写 BoundaryUse 方向/区间关系，保持 ID 到物理面的对应；含方向语义的算子则显式声明不同规则。候选唯一不能替代正确性见证。
- [ ] 区分整结果定义与单面定义；后者 missing/ambiguous/unsupported 时不降级为整结果或默认赋值。
- [ ] 源编辑与必要逻辑基准/定义改写一次同步提交；不引入 identityPending 文件状态，不接受 Worker 自动映射写回。
- [ ] 保存不等 Worker；自动保存、慢求值、撤销、新编辑、换工程和保存失败重试均保持作者态/历史一致。重开只解释保存的定义。
- [ ] 求值前后 Document 编码不变；普通编辑不调用 lineage/spatial fallback 写回，不利用上帧、缓存或历史文件收养候选。
- [ ] 定义解释版本及几何策略变化具有迁移语义；不能升级后静默解析为另一面。
- [ ] 明确 schema 版本；旧六字段引用精确迁移一次，新引用不携带递归 key/lineage 字符串。
- [ ] 外观、浮雕、制造、selected scope、附着、实例复制及公开 API 同时改用新引用；无双权威。
- [ ] V4 基准迁移前后逐定义几何、颜色、厚度、Z、孔洞和成品等价；不能把 V4 ready 当成作者原意正确的证明。
- [ ] 损坏 V4 保留作者态及可定位诊断，不猜测修好；旧解释器只在导入边界运行，不成为新运行时 fallback。
- [ ] 迁移不完整时保护原字节，独立只读检查，不创建混合可写文档或自动覆写；正常 V4 无法表达时阻断发布。
- [ ] 所有当前支持区域及示例可表达并冷重开；不能通过把正常案例标为 unsupported 完成迁移。

验收：工作包 1 全部确定性不变量通过；真实拓扑变化的歧义不会自动串色/串厚度；迁移与普通编辑运行路径分离。仅通过 hash 压缩或删除契约不视为完成。
