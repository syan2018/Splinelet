# 工作包 3：持久区域与迁移

范围：区域 schema/codec、源编辑 ancestry、构造输出注册与解析、全部赋值消费者、复制和旧格式导入。跨模块身份及事务语义由主代理统一决策。

- [ ] 先用正方形反例和局部源编辑证明短 Region ID、用途/实例及区域选择器的独立冷求值。
- [ ] 反转和循环换起点只是表示变更时，命令显式改写 BoundaryUse 方向/区间关系，保持 ID 到物理面的对应；含方向语义的算子则显式声明不同规则。候选唯一不能替代正确性见证。
- [ ] 区分保持、分裂、合并、消失、歧义；受影响而不可确定的赋值进入显式待处理状态。
- [ ] 新源编辑与版本化 identityPending 原子写入；异步接受检查 epoch、revision、ChangeSet、目标槽、规则版本及依赖指纹。保存/撤销为一个语义编辑。
- [ ] 验证自动保存发生在计算中、返回前后撤销、新编辑、换工程和保存失败重试；重开 pending 文件不会把旧绑定当成 ready。
- [ ] 待处理期间赋值表不变，普通编辑不调用 lineage/spatial fallback 写回；冷启动不能搜索并收养一个新候选为旧 ID。
- [ ] 明确 schema 版本；旧六字段引用精确迁移一次，新引用不携带递归 key/lineage 字符串。
- [ ] 外观、浮雕、制造、selected scope、附着、实例复制及公开 API 同时改用新引用；无双权威。
- [ ] 健康 V4 文件迁移前后逐面对应、颜色、厚度、Z、孔洞和成品几何等价；损坏 V4 保留作者态及可定位诊断，不猜测修好。
- [ ] 所有已接受映射可保存重开；不依赖历史文件、上帧网格、索引位置或面积最近匹配。

验收：工作包 1 全部确定性不变量通过；真实拓扑变化的歧义不会自动串色/串厚度；迁移与普通编辑运行路径分离。仅通过 hash 压缩或删除契约不视为完成。
